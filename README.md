# DataMind

Welcome to DataMind! This project is dedicated to data analysis and intelligent insights.

## Project Structure (Monorepo)

This project uses a Monorepo architecture to manage both frontend and backend applications, as well as shared resources.

- `apps/frontend/` - Frontend application (React/Vue)
- `apps/backend/` - Backend application (Node.js/Python)
- `packages/shared-types/` - Shared type definitions between frontend and backend
- `packages/ui-components/` - Reusable UI components
- `docs/` - Project documentation and design specs
- `scripts/` - Automation and utility scripts
- `deploy/` - Deployment configurations (Docker, CI/CD)

## Features

- Data processing and analysis
- Intelligent data visualization
- Machine learning integration
